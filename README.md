# This software converts text files into audiobook videos.
<br /><br />
## Instructions:
<br /><br />
### Install the latest version of Python from https://www.python.org/downloads/windows/ and install.
<br />
### Download Balabolka Command Line Utility from https://www.cross-plus-a.com/balabolka.htm and add balcon.exe to PATH.
<br />
### Download ffmpeg-git-full.7z from https://www.gyan.dev/ffmpeg/builds/ and add ffmpeg.exe to PATH. You can use 7-Zip from https://www.7-zip.org/ to extract the file.
<br />
### Download the Text to Audiobook Converter.py and double-click it.
<br />
### The Text to Audiobook Converter GUI will now run. The Graphical User Interface is intuitive and easy to use. If balcon.exe is not found, specify it's location using the GUI.
